# Prisma

Prisma é uma plataforma de **inteligência organizacional** para RH e Business Partners.

## Proposta de valor

A plataforma transforma dados operacionais de RH em inteligência organizacional acionável, conectando execução tática, leitura organizacional e tomada de decisão estratégica.

## Capacidades centrais

Prisma unifica em um único produto:

- Gestão de atividades de BPs;
- Organograma inteligente;
- Diagnósticos organizacionais;
- Ações de clima;
- Insights com IA;
- Analytics organizacional;
- People intelligence.

## Posicionamento de produto

Prisma deve comunicar uma experiência de software **enterprise moderno** com referência em:

- Microsoft Viva;
- Notion;
- Power BI;
- Linear;
- Copilot.

## O que Prisma não é

A experiência do produto não deve se parecer com:

- ERP antigo;
- Sistema burocrático;
- Ferramenta simples de RH;
- Software legado.

## Princípios de experiência

1. **Clareza executiva:** dashboards e indicadores devem responder rapidamente "o que está acontecendo" e "o que fazer agora".
2. **Fluxo de trabalho integrado:** gestão de atividades e leitura organizacional no mesmo contexto.
3. **IA assistiva e explicável:** insights com recomendações acionáveis e rastreáveis.
4. **Design limpo e confiante:** interface sofisticada, modular e orientada a produtividade.
5. **Escalabilidade enterprise:** visão multiárea, governança de dados e colaboração entre RH e liderança.
